# 克制简洁助手

本目录是一个资产包,不是可执行产物:包里只有 JSON,由 dsc-humanize 内核读取。

| 项 | 内容 |
|:---:|:---:|
| 包标识 | `dsc-humanize-assistant` |
| 版本 | `0.1.1` |
| 格式版本 | `1.0.0` |
| 声明类型 | 人物设定、分类标签集、策略规则、注入文本 |

## 内容清单

| 类型 | 标识 | 一句话 |
|:---:|:---:|:---:|
| 人物设定 | `restrained` | 每次都生效的底线:先答、不重复问题、不铺垫、不编造;约束覆盖中英文回复 |
| 分类标签集 | `quick-fact` | 事实与数字的直接确认 |
| 分类标签集 | `how-to` | 能照做的操作路径 |
| 分类标签集 | `deep-dive` | 原理、机制与取舍分析 |
| 分类标签集 | `casual-chat` | 闲聊与情绪表达 |
| 分类标签集 | `rewrite` | 改写、润色与改语气 |
| 分类标签集 | `code-help` | 报错、日志与接口调用 |
| 策略规则 | `restrained-tone` | 兜底参数加六条按标签收敛的规则 |
| 注入文本 | `answer-first` | 结论在依据之前 |
| 注入文本 | `no-closing` | 不追加服务性收尾 |
| 注入文本 | `plain-wording` | 用事实代替加强词 |
| 注入文本 | `flat-structure` | 能成段就不拆成清单 |
| 注入文本 | `ask-one` | 追问收敛成一个问题 |
| 注入文本 | `contrast-examples` | 六种形状各一组正反对照示例,模仿克制版 |

## 使用约定

- 四类内容的来源由用户分别选择:可以只用这里的人设,也可以只取注入文本,不必整包使用。
- 包内不声明「默认人设」或「默认标签集」,也没有锁定项;导入后可以改、可以再导出。
- 策略规则里的标签引用与同目录的标签集自洽;换用其他标签集时,规则命中的标签需要重新核对。
- 关键词同时收录中文与英文形状信号;规则分类器按子串计分,英文关键词统一小写。
- 包的定位是逼近官方风格的可声明层:不声明任何身份,不承诺与官方参数一致。
